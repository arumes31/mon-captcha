Monster CAPTCHA

A demo of embedding the challenge on a third-party site.

Verification. With data-verify set, the challenge frame exchanges its result for an HMAC-signed token that your backend checks via POST /siteverify. Without it the widget still works, but the token is unverifiable and the callback reports verified: false. See docs/INTEGRATION.md.

What your backend then does

curl -X POST http://localhost:8091/siteverify \
  -H 'content-type: application/json' \
  -d '{"secret":"demo-secret","response":"<the token above>"}'

# => {"success":true,"challenge_ts":"...","hostname":"localhost","points":6}
# A second call with the same token => {"success":false,"error-codes":["timeout-or-duplicate"]}
